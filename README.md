# Statistique des processus : comprendre et calculer

Page d'étude interactive pour le cours de Statistique des processus (ENSAI 3A) : maximum de vraisemblance pour les chaînes de Markov, les processus de Poisson (homogène et Weibull), les processus de Markov de sauts et les modèles de Markov cachés (forward-backward, EM, Viterbi), avec exemples chiffrés, calculateurs, simulations et 13 exercices corrigés.

Ouvrir `index.html` dans un navigateur. Aucune installation, aucun R : tous les calculs tournent dans la page.
